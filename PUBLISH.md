# Публикация

Публичный репозиторий: https://github.com/Ivan25rus/iscc-level-renderer . Обновляйте только файлы этого дополнения. Не добавляйте корневой проект, личную Git-историю, local/, настройки, ключи или отчёты получателя.

Перед публикацией сравните подготовленное дерево с текущей веткой `main` и проверьте манифест. После слияния создайте выпуск на проверенном коммите и приложите архив с тем же содержимым. Скачайте опубликованный архив и сверьте его контрольную сумму. В описании выпуска перечислите изменения из [CHANGELOG.md](CHANGELOG.md).

`SETUP.html` открывается локально после распаковки. `index.html` содержит то же меню для GitHub Pages. Меню формирует локальный план установки без сетевых запросов.

Pull Request автору — отдельное действие: создайте ветку от репозитория автора, перенесите модуль и минимальные интеграционные изменения, запустите проверки и опишите зависимости. Не переносите в PR всю личную панель или несвязанную Git-историю. Права на публичное распространение исходных производных изменений требуют уточнения у автора; пакет не приписывает им несуществующую лицензию.

Для коммитов этого проекта используйте GitHub-адрес noreply. Настройки почты всего аккаунта менять не требуется. Реальная установка и компиляция индикатора проверяются на компьютере получателя отдельно от тестов исходников.
